# 성적 내보내기 가이드

학생별 문제 점수와 총점을 확인하고 CSV로 내려받는 방법입니다. **관리자 계정과 수강생 명단**을 준비해 주세요.

## 1. 화면 열기와 다운로드

1. 관리자로 로그인한 뒤 **Plugins → Submission Export**를 엽니다. 직접 경로는 `/admin/submission_export/`입니다.
2. 학생의 이름·이메일·학번과 문제별 점수를 확인합니다. 화면의 Account status에는 이용 정지(Banned), 숨김(Hidden) 또는 Active가 표시됩니다.
3. **Export to CSV**를 누르면 `submission_export.csv`를 내려받을 수 있습니다.

## 2. 각 열의 의미

| 열 | 의미 |
|---|---|
| Name | 화면에 표시하는 이름(Nickname). 동명이인이 있을 수 있습니다. |
| Email | 계정 이메일 |
| Student ID | `Student ID Number` 사용자 필드의 학번 |
| Banned / Hidden | 계정의 이용 정지·숨김 여부 |
| 문제명 (ID: 번호) | 정답 제출 기록이 있으면 해당 문제의 현재 점수, 그 외에는 0 |
| Total Score | 내보낸 문제별 점수의 합계 |

모든 일반 사용자 계정과 모든 문제를 포함합니다. 이용 정지·숨김 학생도 행이 유지되며 관리자 계정은 제외됩니다. 테스트 계정과 다른 수업의 계정이 함께 있다면 **학번으로 수강생을 선별해야 합니다.** 과제·시험별 점수가 필요하면 해당 문제 열을 선택해 계산해 주세요.

## 3. 성적 처리 전 대조

- CSV를 스프레드시트에서 가져올 때 Student ID 열을 **텍스트**로 지정하는 것이 좋습니다. 숫자로 읽으면 앞자리 0이 사라질 수 있습니다. 파일은 한글 표시를 위한 UTF-8 BOM을 포함합니다.
- 동명이인은 학번·이메일로 대조해야 합니다. 학번이 비어 있거나 화면에 N/A가 보이면 관리자 사용자 화면에서 해당 학생의 학번 필드를 확인해 주세요.
- 예제 학생 한 명의 정답 제출 기록을 문제 점수·총점과 대조하는 것이 좋습니다. 제출 기록의 시각·SQL 확인은 관리자 제출 기록 화면에서 진행할 수 있습니다.
- 이 표는 문제의 **현재 배점**으로 합산하므로, 성적 확정 후 배점을 바꾸려면 이전에 내려받은 성적과의 차이를 먼저 확인해야 합니다.
- 개인 수강생의 정답 기록을 기준으로 만드는 표입니다. 팀 모드나 가산점(Awards)을 사용하는 수업은 공식 성적에 반영할 범위를 따로 확인해야 합니다.

CSV에는 이름·학번·이메일이 있으므로 수업의 접근 제한 저장소에 보관해야 합니다. 성적 처리 날짜, 대상 수강생 명단, 선택한 문제 열과 배점을 함께 기록하는 것이 좋습니다.

제출부터 CSV까지 전체 흐름을 확인하려면 [제출 점검 가이드](../sql_challenges/SUBMISSION_REVIEW.md)를 참고해 주세요.
