# SQL PlayZone 이용 약관 및 데이터 수집 안내

SQL PlayZone은 한양대학교 데이터베이스 수업의 SQL 퀴즈와 시험을 위한 플랫폼입니다. 계정을 만들고 이용하려면 아래 내용에 동의해야 합니다.

## 1. 계정

- 계정은 한양대학교 Google 계정으로만 만들 수 있으며 수업 수강생에게만 제공됩니다.
- 아이디와 비밀번호는 본인만 사용해야 하며 다른 사람과 공유할 수 없습니다.
- 학번은 채점 결과를 수강생과 대조하기 위해 사용합니다.

## 2. 수집하는 정보

플랫폼은 수업 운영과 채점을 위해 다음 정보를 기록합니다.

- 계정 정보: 이름, 이메일, 학번, 로그인 시각과 IP 주소
- 문제 풀이 기록: 제출(Submit)한 SQL과 채점 결과, 실행(Test/Execute)한 SQL과 그 결과, 각 기록의 시각
- 풀이 화면에서의 행동 기록: 붙여넣기, 창(탭) 전환 등 부정행위 확인에 필요한 이벤트

## 3. 이용 목적

- 퀴즈와 시험의 채점, 성적 처리
- 부정행위 확인과 시험 운영
- 수업 개선과 교육 연구. 연구에 사용할 때는 개인을 알아볼 수 없도록 처리합니다.

## 4. 보관과 문의

- 기록은 수업 운영과 성적 처리에 필요한 기간 동안 보관합니다.
- 기록의 열람, 정정, 삭제 요청은 담당 조교에게 문의하십시오.

## 5. 이용 규칙

- 시험 중에는 안내된 자료와 도구만 사용해야 합니다. 다른 사람과 답을 주고받거나 외부 도구로 답을 생성하는 행위는 부정행위로 처리됩니다.
- 플랫폼이나 채점 시스템을 고의로 방해하거나 우회하려는 행위는 금지됩니다.
